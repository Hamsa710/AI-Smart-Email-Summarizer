# AI-Powered Smart Email & Article Summarizer

## Overview
This project summarizes lengthy emails and articles using NLP and Hugging Face Transformers.

## Features
- Email and Article Summarization
- Multiple Summary Lengths
- TXT File Upload
- Download Summary
- Word Count Statistics
- Text Reduction Percentage

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- BART Model

## Run Locally

pip install -r requirements.txt

streamlit run app.py
